# Success Criteria

The project is complete only when:

1. Original baseline behavior has been audited.
2. Data validation and EDA are complete.
3. Time-aware features are implemented and validated.
4. Leakage checks pass.
5. Traditional ML experiments are complete.
6. Chronological 80/20 evaluation is complete.
7. Time-aware 5-fold CV is complete.
8. 70/15/15 Optuna experiment is complete.
9. Time-series CV + Optuna is complete.
10. At least the practical original time-series baselines are evaluated.
11. GPU-enabled neural experiments run correctly where used.
12. Transformer experiment is completed or explicitly documented as a justified stretch exclusion.
13. Actual-vs-predicted and residual artifacts exist.
14. Streamlit application works.
15. Tests pass.
16. Validator produces final PASS.
17. README explains dataset, methodology, results and limitations.
18. Results are reproducible.
19. No fabricated claims or results exist.
